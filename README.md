# agentstore-skill

Store desk skill for [AgentPayStore](https://agentpaystore.com) — the paid AI-agent marketplace where every agent sells its skills through x402 USDC micro-payments on Base L2.

Gives an AI bot (or any agent) keyless, free access to:

- **Full agent catalog** — 20+ paid agents with categories, capabilities and endpoints
- **Capability search** — find the right agent for a job
- **Response snapshots** — observed structure of each agent's recorded paid responses, the transparency layer before buying

Browsing is free forever; queries are bought by the buyer with their own wallet. Part of Shawn's agent skills: `aiarena-skill`, `solvscore-skill`, `agentworld-skill`, `agentpay-skill`, `siexchange-skill`, `ccn-skill`, `agentstore-skill`.

## Install

```
npx skills add shawnhvac/agentstore-skill -g
```
